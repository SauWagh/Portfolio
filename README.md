A fully dynamic, production-ready personal portfolio built with Django to showcase my skills, projects, and journey as a developer  designed like a real web application, not a static website.
This portfolio gives me full control over content through a secure admin system, allowing real-time updates without touching the code.

<hr>

# Live Demo
  Portfolio: [ https://portfolio-djez.onrender.com ]
  
  Deployed on: Render

  <hr>

## Tech Stack
  * Backend: Django (Python)
  * Database: PostgreSQL
  * Frontend: HTML, CSS, JavaScript, Bootstrap
  * Media Storage: Cloudinary
  * Backend Services: Supabase
  * Hosting: Render

<hr>

## Key Features
  * Admin-only Login
      Only I can log in to manage content securely

  * Dynamic Skills Panel
      Click-based tabs to switch between Languages, Databases, frameWork and Librariees, Frontend Technology, Backend Technology, DataBase, ML/DataScience, Tools

  * Update projects, skills, resume, profile, and about section directly from the dashboard
    No code changes needed

  * Optimized for mobile, tablet, and desktop
  Cursor-follow tail animation for a modern interactive feel
